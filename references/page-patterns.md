# 页面模式

按内容需求选用以下模式。它们是构图参考，不要求固定路由、固定组件数量或特定框架。

## 个人首页 / 内容入口

宽屏可用主内容与辅助侧栏：主区域承载介绍、近期活动或精选内容；侧栏承载身份、导航、社交入口和轻量统计。Navfolio 的参考尺度是主栏 760px、侧栏 240–286px、栏间距 42px，受整体容器约束。

窄屏按读者任务重排：身份与关键入口可以先于长介绍，次要统计后置。仅在视觉和 DOM 阅读顺序仍合理时使用 CSS 排序；键盘及屏幕阅读器顺序也应连贯。内容较少时单栏更合适。

介绍可以有较大的标题和个人化语气，避免强行添加营销标语、装饰插图或不存在的数据。

## 列表 / 索引

页头包含可选栏目标签、页面标题和简短说明。下方可按需提供分类、搜索或筛选，再进入连续列表。

默认行结构为标题、摘要、日期或类别，加可选缩略图。使用细分隔线和垂直间距维持节奏；缩略图缺失时文字自然占用空间，不保留空白占位。长标题、无摘要或标签过多时，行高随内容增长，避免照搬示例中的固定高度。

只有用户需要独立浏览、对比或操作每个对象时，才选卡片网格。分类导航和元信息保持紧凑，主要内容保持充足空间。

## 文章 / 知识详情

标题与元信息建立入口，正文控制阅读宽度。宽屏目录作为辅助，窄屏可折叠或进入正文上方。折叠控件需要清楚的状态和键盘操作。

正文通过标题间距、段落节奏、链接与引用样式建立秩序。图片保持比例；代码和宽表格局部滚动。说明块使用柔和表面或细侧线；错误和警告仍保留其状态辨识度。

相关推荐、作者信息和前后篇导航放在文章边界，不与正文争夺主要视觉位置。

## 迁移到其他界面

作品集沿用标题层级、轻边界与留白，允许作品图像承担视觉重点；知识库优先目录、搜索和阅读区；工具页保持表单与结果层次，按任务密度收紧间距。

迁移时保留目标产品的信息架构、功能和语义。不要把个人首页的头像、热力图、统计、双栏布局当作 Navfolio 风格的必要条件。
