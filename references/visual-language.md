# 视觉语言

## 气质与视觉重心

Navfolio Editorial 面向持续阅读和个人表达：像一本整理清楚、留有呼吸空间的个人刊物。主要特征是柔和的纸白或深色纸面、清楚的墨色文字、低饱和强调色、轻边界和有节奏的内容分组。

这些特征可以迁移到任何技术栈。保留内容主次与阅读节奏，比复制某个页面的像素更重要。

## 色彩与表面

- 区分页面底色、主要表面、次级表面、正文、次要文字、边界、强调色及其淡背景。
- 默认绿色偏灰，亦可选择蓝、紫、玫瑰、粉、橙、棕等色彩家族。换色时同步调整强调文字、淡背景和交互状态。
- 降低大面积背景、阴影和装饰线的存在感；不要为了柔和而降低正文可读性。
- 纸感主要来自暖白底色、轻微表面差异和排版。纹理是可选增强，不能干扰文字，也不必依赖图片资源。
- 小圆角、细边框、短而浅的阴影用于独立区域。文章流和连续列表常适合透明背景、直边分隔。
- 避免无业务理由的大面积高饱和渐变、强玻璃模糊、厚重浮层和多层卡片。用户明确要求这些特征时应服从需求，说明风格发生了怎样的适配。

## 排版与节奏

标题用尺度和留白建立层级，不默认依赖极粗字重。正文行距宽松；日期、分类、标签、计数更紧凑，但仍保持可读。

按字体角色设置样式，不根据变量名推断字体外观。Navfolio 当前部分带 serif 名称的变量实际指向中文 UI 字体。

参考组合为 Maple Mono 英文、ChillRoundM 中文、Monaco 代码。它们不是技能运行前提：目标项目没有这些字体时使用已有字体和系统后备，不自动下载或分发字体。采用相近气质时也需检查字宽、中文标点、粗体和代码对齐。

为标题和正文设计不同的段落节奏：章节之前留出比章节之后更大的距离；相关元信息紧邻内容；不同内容组之间留出更明显的空间。英文小型栏目标签可适度增加字距，中文标题保持自然字距。

## 交互与动态

链接应有位置、下划线或其他明确线索；正文链接尤其不能只依赖轻微色差。按钮有清楚的默认、hover、focus-visible 与 disabled 状态。

参考反馈为约 180ms 的颜色或边界过渡、最多 1px 的轻上移。可选入场效果约 420ms；不要全站元素逐项延迟出现。尊重 prefers-reduced-motion，关闭非必要位移与入场动画。

触屏保留可发现且易点按的操作；图标按钮提供可访问名称。暗色模式保持文字和背景的层次，避免将浅色值机械反相。
