# 设计参数参考

以下取自 Navfolio 默认主题的代表性值，作为设计起点。它们不是跨项目必须遵守的完整 token 标准，也不承诺每种文字尺寸与背景组合都通过对比度检查。实现时核对实际使用场景。

## 默认绿色家族

| 语义 | 浅色 | 暗色 |
| --- | --- | --- |
| 页面背景 | #fdfdf9 | #171b18 |
| 主要表面 | #fffffc | #202620 |
| 次级表面 | #f7f8f3 | #273026 |
| 正文 | #272d28 | #eaebe5 |
| 次要文字 | #667066 | #b5beb1 |
| 淡化文字参考 | #90998f | #899487 |
| 细边界 | rgba(31,35,40,.075) | rgba(217,229,213,.08) |
| 加强边界 | rgba(31,35,40,.12) | rgba(217,229,213,.14) |
| 强调色 | #667d6d | #a8baa9 |
| 强调淡背景 | #edf3ed | #2b372d |

淡化文字不能直接用作小字号必要信息；优先使用次要文字色，按对比度结果调整。细边界适合装饰性分隔，必要输入控件与焦点使用更明确的轮廓。

浅色参考阴影：`0 1px 2px rgba(31,35,40,.03), 0 4px 12px rgba(31,35,40,.02)`。
暗色参考阴影：`0 1px 2px rgba(0,0,0,.14), 0 4px 12px rgba(0,0,0,.08)`。

## 尺度

| 用途 | 参考起点 | 调整依据 |
| --- | --- | --- |
| 页面容器 | 1168px 上限 | 页面类型和信息密度 |
| 阅读区 | 760px 上限 | 实际字宽和行长；不要让长文无限拉宽 |
| 水平边距 | 桌面 32px、窄屏 18px | 屏幕宽度和控件空间 |
| 正文 | 18px / 1.75 | 字体、语言和阅读距离 |
| UI 基础文字 | 16px / 1.8 | 表单、列表与导航各自的密度 |
| 页面标题 | clamp(2.4rem, 5.5vw, 4rem) | 长标题、窄屏换行 |
| 正文二级标题 | 1.9rem / 1.2 | 章节之前 56px、之后 20px 作为起点 |
| 面板圆角 | 6–8px | 同类组件保持一致；行列表可为 0 |
| 轻反馈 | 180ms | 减少动态效果偏好和操作频率 |

这些值来自不同语境，不能不加判断地全部应用到同一元素。主站固定导航下的顶部留白也不适合照搬到没有固定导航的项目。

## 映射到目标项目

优先复用现有语义：page/background、surface、text/primary、text/muted、border、accent、font/body、font/heading、font/code。没有语义体系时再新增范围清楚的变量；不要把色值分散进每个组件。

在 Navfolio 内对应变量主要是 `--paper-*`、`--font-*`、`--layout-*`。在其他项目中无需保留这些命名。

新增色彩家族时先确定强调色与淡背景，再校正明暗两组状态。保留成功、警告、错误等业务状态的语义，不能把所有状态统一成品牌绿色。
